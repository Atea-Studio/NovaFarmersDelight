# Changelog

## Nova 0.25

### Gameplay additions

- Added the Stove and Skillet cooking blocks and the Basket storage blocks.
- Added furniture from the original Farmer's Delight mod.

### Bug fixes

- Fixed cutting board item stacking.
- Made muddy farmland waterloggable.
- Added comparator and hopper compatibility for containers.
- Fixed the cooking pot recipe GUI to display the recipe's explicit container.

### Other changes

- Updated the addon to Nova 0.25.
